## v2.1.9 の主な修正 / Highlights

- **v2.1.6形式のReleaseに再整理**  
  Release本文に全成果物のダウンロード表を置き、Windows installer / Windows portable / macOS / Linux / Ubuntu / Android APK を同じReleaseへ揃えます。

- **GUIの安定性を追加補強**  
  リサイズ連打、テーマ再構築、Focus停止後のHome復帰、コンパクト画面切替で古いTk/CTK widget参照を触るケースをさらにガードしました。

- **描画エラー時の安全フォールバック**  
  FocusアニメーションやCanvas描画で例外が出ても、空白画面や半端な描画で止まらず、最小限のAqua背景へ戻して次のtickで復帰しやすくしました。

- **Focus UI再スケール強化**  
  update loop後にも時計サイズ、Focus操作UI、二次操作ボタンの配置を補正して、巨大化・ズレ・隠れを抑えます。

- **アニメーション拡張の即時反映**  
  `extensions.json` をFocus中にも再読込し、Extensionsでアニメーションをインストール/削除した時に再起動なしで描画へ反映します。

- **AGIU更新判定の現在版をv2.1.9へ更新**  
  デスクトップ更新機能がv2.1.9を現在版として扱います。

- **Android v2.1.9配布対応**  
  Buildozerの `version = 2.1.9` / `android.numeric_version = 219`、Android workflowの成果物名、Release添付先をv2.1.9へ統一しました。
