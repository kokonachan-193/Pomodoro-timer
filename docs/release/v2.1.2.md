## Fixed

### Duplicate / stacked Home bug
The clean Home was being mounted twice during startup. After a theme refresh this could leave two differently colored Home surfaces stacked vertically in one window.

v2.1.2:
- removes the duplicate startup mount
- makes Home installation idempotent
- destroys stale Home surfaces before rebuilding
- prevents split-screen / ghost copies after theme changes

### Small and large window behavior
Home now uses real responsive breakpoints instead of one fixed desktop card.

- Compact
- Normal
- Wide
- Ultra

The UI now adapts:
- card width
- outer gutters
- title size
- timer size
- input height
- primary action height
- top utility controls

This keeps the app usable in a smaller utility window while also preventing the center card from looking tiny on large or 4K displays.

The distraction-reduced Focus screen remains:
- large timer

- current intention

- controls that auto-hide and reappear on interaction

## 日本語

v2.1.2では、スクリーンショットで発生していた **Homeが上下に2枚表示されるバグ** を修正しました。

原因は起動時に新Homeの `install()` が2回呼ばれていたことでした。さらにテーマ変更時の再構築でも古いsurfaceが残らないよう、Homeの生成処理自体を安全化しています。

また、
- 小さいウィンドウでも崩れない
- 大画面/4Kでも中央だけ極端に小さくならない
- GUIはシンプルなまま
- 以前の機能は削らない

という方針に調整しました。

`…` には Tasks / Stats / Extensions / Music Library / Soundscape / Countdown / Stopwatch / Alarm / Custom Session などを整理し、Settingsには Theme / 背景 / 言語 / 音声出力 / Focus Lock / 更新設定を戻しています。

さらに `… → Full controls` から旧画面の全コントロールを開けるため、v2.1以前の機能は残したまま使えます。
