## 修正 / Fixes

- **全配布対象をv2.1.8で統一**  
  Windows installer / Windows portable / macOS / Linux / Ubuntu / Android APK を同じ v2.1.8 Release に添付します。

- **Focus中のアニメーション拡張反映**  
  Extensionsでアニメーションをインストール/削除した時、Focus画面を再起動しなくても描画へ即時反映します。

- **拡張状態の再読込を強化**  
  `draw_focus_canvas` と `draw_waves` の両方で `extensions.json` の更新を検知し、保存済み状態を再読込します。

- **初回インストールと削除状態の分離**  
  初回起動時は組み込みアニメーションを登録しますが、その後ユーザーが削除したアニメーションを勝手に復活させないようにしました。

- **GUI表示バグ対策**  
  リサイズ・テーマ再構築・Focus終了時に古いTk/CTk widget参照を触って表示が崩れるケースを軽減しました。

- **Focus描画の安全フォールバック**  
  アニメーション描画で例外が出てもタイマー画面全体を壊さず、最小限の背景と進行円に戻して次のtickで復帰できるようにしました。

- **Focus時計のサイズ固定バグ対策**  
  v3 Focus画面で毎tick 94px固定へ戻る処理を抑え、画面サイズに応じたスケールを維持します。

- **Android v2.1.8配布対応**  
  Buildozerの `version = 2.1.8` / `android.numeric_version = 218`、Android workflowの成果物名、Release添付先をv2.1.8へ統一しました。

- **Source実行/Packaged実行の両対応**  
  `sitecustomize.py` は `python main.py` の通常起動用、`pyinstaller_runtime_hook.py` は配布ビルド用に同じ修正を読み込みます。

## UI方針 / UI direction

- 余白を活かしたシンプルなHome
- 集中時は情報量を抑え、時計・進行円・水面演出を中心にする
- 高度な設定は `•••` と拡張画面へ逃がす
- 小さい画面でもカードが切れにくいレスポンシブ構成
- 派手すぎない、静かでおしゃれなモダンポモドーロ

## 検証 / Validation

- Extensionsで Sakura / Rain / Snow / Fireflies / Fish などを削除・再追加してFocus中に反映されること
- Focus中に小さい画面へリサイズして時計表示が極端に戻らないこと
