# Aqua Focus v2.1.8

PC版のGUI安定性とFocus中のアニメーション拡張反映を修正するデスクトップ向け更新です。  
Desktop update focused on GUI stability and live Focus animation extension behavior.

---

## 修正 / Fixes

- **Focus中のアニメーション拡張反映**  
  Extensionsでアニメーションをインストール/削除した時、Focus画面を再起動しなくても描画へ即時反映します。

- **拡張状態の再読込**  
  Focus描画中に `extensions.json` の更新を検知し、保存済み状態を再読込します。

- **初回インストールと削除状態の分離**  
  初回起動時は組み込みアニメーションを登録しますが、その後ユーザーが削除したアニメーションを勝手に復活させないようにしました。

- **GUI表示バグ対策**  
  リサイズ・テーマ再構築・Focus終了時に古いTk/CTk widget参照を触って表示が崩れるケースを軽減しました。

- **Focus時計のサイズ固定バグ対策**  
  v3 Focus画面で毎tick 94px固定へ戻る処理を抑え、画面サイズに応じたスケールを維持します。

- **Source実行/Packaged実行の両対応**  
  `sitecustomize.py` は `python main.py` の通常起動用、`pyinstaller_runtime_hook.py` は配布ビルド用に同じ修正を読み込みます。

## 検証 / Validation

- Extensionsで Sakura / Rain / Snow / Fireflies / Fish などを削除・再追加してFocus中に反映されること
- Focus中に小さい画面へリサイズして時計表示が極端に戻らないこと
- Focus停止後にHomeへ戻ってもレイアウトが崩れにくいこと
- PyInstallerビルドで runtime hook が同梱されること
