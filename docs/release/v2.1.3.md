# Aqua Focus v2.1.3 — Full dashboard restored

v2.1.3 changes direction from the overly sparse v2.1.2 Home and restores the feature-complete dashboard as the default experience.

## Changed

- Restored the full dashboard as the default UI.
- Restored direct visibility of Quick Dive, timing controls, rhythm preview, intention, music, playlist and volume controls.
- Restored the full sidebar with workspace, language, audio output, updater, Focus Lock, presets, theme and background controls.
- Applied restrained visual cleanup: calmer spacing, consistent card radii and borders, smaller hero/header proportions and more balanced buttons.
- Kept the previous CTkEntry lifecycle fix so hidden legacy controls are not destroyed underneath timer logic.
- Kept Focus, Deep Dive, Countdown, Stopwatch and Alarm behavior.

## 日本語

v2.1.3では、機能を隠しすぎていたミニマルHomeをやめ、**機能が見えるフルダッシュボードをデフォルトに戻しました**。

GUIは全面的に作り直すのではなく、余白・角丸・枠線・文字サイズ・ボタン比率を控えめに整理しています。タイマー設定、Quick Dive、リズム、目的、音楽、プレイリスト、音量、サイドバーの各設定を再び直接操作できます。

また、v2.1.2で修正した `CTkEntry invalid command name` の原因となるウィジェット破壊問題は再発しないよう維持しています。
