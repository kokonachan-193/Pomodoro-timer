# Aqua Focus v2.1.4

This release focuses on stability, responsive layout, and restoring the visual/interactive feel without removing existing functionality.

## Fixed
- Prevents the startup/preset crash: `_tkinter.TclError: invalid command name "...ctkentry.!entry"`.
- Preset application now checks widget liveness before touching CTkEntry instances and keeps timer state authoritative even if a compatibility view is temporarily unavailable.
- Compact-window behavior no longer destroys the legacy control surface, preventing stale Tcl widget handles.

## Responsive GUI
- The main dashboard adapts from small utility windows through large and ultrawide displays.
- On compact widths the sidebar is hidden, not destroyed, and all advanced features remain reachable through the `•••` menu.
- On large displays cards stay readable instead of stretching across the entire monitor.
- Typography, spacing, card widths, controls, and the animated hero scale down without removing features.

## Focus experience
- The focus menu remains available during sessions.
- Tracks can be added and playlist navigation remains accessible without leaving focus.
- A subtle waterline now rises with elapsed focus time.
- Reduce Motion keeps the progress metaphor but disables the animated wave motion.

## Features preserved
Focus / Deep Dive / Countdown / Stopwatch / Alarm, custom timing, long breaks, intention, YouTube/Spotify-matched/direct audio, playlist, volume, audio output, Tasks, Stats, Ocean Soundscape, Extensions, Focus Lock, themes, backgrounds, language, updater, AGIU and accessibility options remain available.
