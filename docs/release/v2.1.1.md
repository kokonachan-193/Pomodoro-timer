# Aqua Focus v2.1.1 — Compact responsive fix

**Smaller window. Same focus. No broken layout.**

v2.1.1 is a focused stability and usability release for the attention-first interface introduced in v2.1.0.

The main goal of this update is simple: **Aqua Focus should remain clean and usable even when the window is made much smaller.**

## What changed

### Compact window support
- default desktop window reduced from **1180×780** to **980×680**
- minimum desktop window reduced from **940×640** to **560×520**
- Home now continuously responds to the actual available viewport
- the main focus card no longer stays stuck at a desktop-only width
- outer gutters automatically tighten on smaller windows
- vertical spacing is reduced when window height is limited

### Responsive Home
The attention-first Home introduced in v2.1.0 now adapts instead of clipping.

- header actions reflow when horizontal room becomes limited
- brand and utility actions switch to a two-row layout on very narrow windows
- focus card width follows the viewport
- session title typography scales down progressively
- the large duration display scales down progressively
- primary controls remain readable and clickable instead of being aggressively shrunk
- resize handling is debounced to avoid unnecessary layout work while dragging the window

### Responsive Focus view
The active Focus screen now follows the same compact-window rules.

- the large timer typography scales with available canvas size
- Pause / Stop controls adapt their width
- progress ring adapts to smaller canvases
- music and control-bar placement is adjusted on short / narrow layouts
- minimum typography and control sizes are preserved for readability

### Fixed the underlying sizing mismatch
The previous responsive patch improved the visible Home layout, but the legacy application window still enforced a **940×640 minimum size**.

v2.1.1 removes that mismatch, so the new compact interface can actually operate at compact desktop sizes.

## 日本語

v2.1.1 は、v2.1.0 で刷新したGUIの **小画面・ウィンドウ縮小時の崩れを総合的に修正するアップデート** です。

これまでは見た目側をレスポンシブ化していても、アプリ本体に **最小 940×640** の古い制約が残っていたため、実際には十分小さくできなかったり、縮小時にカードや操作部が不自然になる箇所が残っていました。

今回の更新では、

- 初期サイズを **980×680** に小型化
- 最小サイズを **560×520** に変更
- ウィンドウ幅に応じてフォーカスカードを自動縮小
- 狭い画面では上部ヘッダーを2段化
- 余白を自動で縮小
- タイトル・時間表示を段階的に縮小
- Focus中の大きなタイマーも画面サイズに追従
- Pause / Stop ボタンも小画面向けに調整
- 進捗リング・音楽表示・操作バー位置も補正
- リサイズ中の再計算をデバウンスして無駄な処理を削減

という形で、**「画面を小さくしても同じように使える」ことをGUI全体に適用**しました。

v2.1.0で追加した「1タスク・1セッション」を中心にした設計や、Tasks / Stats / Soundscape / Extensions 等の機能はそのまま残っています。
