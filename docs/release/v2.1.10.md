## v2.1.10 の主な修正 / Highlights

- **アニメーション拡張がONでも何も起きないように見える問題を修正**  
  Focus描画の上に専用FXレイヤーを追加し、桜・雨・雪・蛍・魚・泡・粒子が暗い背景画像の上でも見えるようにしました。

- **桜 / 雨 / 雪 / 蛍 / 魚を視認しやすく調整**  
  以前より数・速度・発光・明るさを上げ、ONにした直後に反応が分かるバランスへ変更しました。

- **拡張ON/OFFの即時反映を強化**  
  `extensions.json` をFocus中にも再読込し、保存直後に複数回再描画することで「インストールしても消しても変わらない」状態を減らしました。

- **Reduce Motionでも完全に消えないよう修正**  
  Reduce Motion時は動きを抑えつつ、ON状態が分かる静かなFX表示を残します。

- **Focus描画の安全性を維持**  
  アニメーション描画で例外が出てもタイマー画面を壊さず、Aquaの安全フレームに戻して継続します。

- **Windowsインストーラ版数の固定問題も修正済み**  
  Inno Setupへ workflow の `VERSION` を渡し、`AquaFocusSetup-2.1.10.exe` が正しく生成されるようにしています。

- **AGIU更新判定の現在版をv2.1.10へ更新**  
  デスクトップ更新機能がv2.1.10を現在版として扱います。

- **Android v2.1.10配布対応**  
  Buildozerの `version = 2.1.10` / `android.numeric_version = 2110`、Android workflowの成果物名、Release添付先、APK内の `APP_VERSION` スタンプをv2.1.10へ統一しました。
