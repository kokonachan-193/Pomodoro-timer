# Aqua Focus v2.0.0 — Deep Sea Focus

**Descend into focus.**

Aqua Focus v2 rebuilds the experience around a calmer, underwater workspace while keeping the reliable timer and music engine from v1.x.

## What changed

### Deep Sea interface
- animated caustic light and bubbles
- deep-ocean glass styling
- calmer spacing and visual hierarchy
- Reduce Motion option

### New focus modes
- Focus
- Deep Dive (90 min)
- Countdown
- Stopwatch / Flow foundation
- Blue Alarm

### Workspace
- Coral Tasks with focused-minute attribution
- Abyss Stats with daily / weekly / total focus time
- 7-day activity chart and recent-session history
- Ocean Soundscape: Ocean / Rain / Brown Noise ambient layer

### Extensions
- Reef Extensions manager
- GitHub-hosted online catalog
- theme / preset / sound extension metadata foundation

### Music
- keeps v1.2's yt-dlp + ffmpeg reliability improvements
- required HTTP headers are preserved
- stream failure can fall back to local playback
- OS default audio output can be selected automatically

### Platforms
- Windows installer + portable
- macOS
- Linux / Ubuntu
- Android APK
