# Aqua Focus v2.1.5 — Modern v2.1.2 Home

Aqua Focus v2.1.5 brings back the clean, focused interaction model from v2.1.2 and keeps the functionality added afterward.

## What changed

- Restored the v2.1.2-style Home: one task, one session length, one primary Start action.
- Modernized card, input, spacing, border and primary-action styling.
- Kept Tasks, Stats, Settings and the full feature menu easy to reach.
- Preserved Custom Session, Countdown, Stopwatch, Alarm, Extensions, Music Library, Ambient Sound and Full Controls.
- Preserved in-focus music access, responsive Focus chrome and the rising-water progress animation.
- Hardened stale CustomTkinter entry access that could cause `invalid command name` crashes.
- Kept compact, standard and ultrawide layouts responsive without removing features.

## Release validation

Before publishing, the release pipeline runs:
- Python syntax checks.
- A headless GUI smoke test covering Home presets, Tasks, Stats, Settings, More, auxiliary timers, Music Library, Full Controls, and Focus start/pause/resume/stop.
- Compact / standard / wide / Focus screenshot generation.
- Windows, Linux/Ubuntu and macOS package builds.
