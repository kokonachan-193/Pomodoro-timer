This release focuses on Android text rendering, responsive layout, Focus visuals, and release signing.

## Android修正 / Android fixes

- **日本語文字化け対策**  
  CIで Noto CJK / JP フォントをAPKに同梱し、アプリ起動時は同梱フォントを最優先で登録します。

- **フォント未検出時の安全動作**  
  日本語対応フォントを登録できない端末では、豆腐表示や文字化けを避けるため自動で英語UIに切り替えます。

- **小型画面のUI崩れ修正**  
  画面幅・高さに応じて時計サイズ、余白、ボタン高、Focus表示領域を可変化しました。

- **TextInputフォーカス時の崩れ対策**  
  Androidキーボード表示時は `Window.softinput_mode = "pan"` を使い、入力欄フォーカスで画面が壊れにくいようにしました。

- **波アニメーション安定化**  
  水面と波メッシュの座標を画面内に制限し、端や上下で波が破綻しないようにしました。

- **桜の花びら演出を追加**  
  深海Focus演出に、軽量な桜の花びらを追加しました。演出パネルからON/OFFできます。

- **Reduce Motion追加**  
  動きが強すぎる場合に、水中光・泡・桜などのモーションを抑える設定を追加しました。

- **APK署名情報の表示**  
  Android版フッターに署名証明書のSHA-256短縮表示を追加しました。

## 署名 / Signing

GitHub Actions は以下のSecretsが設定されている場合、release APKを `apksigner` で署名し、証明書情報を `AquaFocus-Android-2.1.7.certs.txt` として添付します。

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

Secretsが未設定の場合は、開発を止めないため debug APK を作成します。

> Androidの仕様上、Google Play外からAPKを直接インストールする場合は、端末側で「提供元不明アプリ」などの警告が出ることがあります。署名はアプリ作成者と更新経路を固定するためのもので、すべての野良APK警告を完全に消すものではありません。警告を最小化するにはGoogle Playなど信頼済み配布経路を使ってください。

署名手順: [`docs/android-signing.md`](../android-signing.md)
