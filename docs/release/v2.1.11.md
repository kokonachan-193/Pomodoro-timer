## v2.1.11 の主な修正 / Highlights

- **水面上昇が不自然な帯に見える問題を修正**  
  旧描画ではテーマアクセント色を水として使っていたため、ピンク系テーマや背景画像では水がマゼンタの帯のように見えることがありました。v2.1.11では水系だけ専用の青いAquaレイヤーへ差し替えました。

- **`animation-rising-water` を落ち着いた上昇に変更**  
  早い段階で水位が太く出すぎないよう、水位上昇をsmoothstepで補正し、開始直後はほぼ底面、進行に合わせて自然に上がるようにしました。

- **泡・カースティクス・発光粒子を水面下に制限**  
  `animation-bubbles` / `animation-caustics` / `animation-bioluminescence` / `animation-depth-particles` が水面より上に出たり、画面全体に散らばりすぎたりしないようにしました。

- **古い水描画だけを抑止**  
  桜・雨・雪・蛍・魚など他の拡張はv2.1.10の見えやすい描画を維持し、水系だけを `pc_water_fixes.py` で上書きしています。

- **Canvas itemの蓄積を防止**  
  水系FXは `pc_water_fx` タグで毎回削除してから再描画するため、Focus中に同じ水面や泡が重なって増え続ける問題を防ぎます。

- **通常起動・配布版の両方で有効**  
  `sitecustomize.py` と `pyinstaller_runtime_hook.py` に `pc_water_fixes.py` を追加し、PyInstaller specにも同梱しました。

- **AGIU補正**  
  v2.1.11パッケージではAGIUの現在版も `2.1.11` として扱います。
