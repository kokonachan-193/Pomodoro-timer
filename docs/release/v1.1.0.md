## Highlights

- **AGIU** — in-app update from GitHub Releases (Windows / macOS / Linux)
- **Audio output** — choose the playback device; nothing is auto-selected for you
- Focus music (YouTube / Spotify / direct) during work only
- Temptation guard · 日本語 / English UI · science presets

---

## Install tips

**Windows** — run the Setup, or unzip the portable folder anywhere.  
**macOS** — if Gatekeeper blocks the app: right-click → Open (first launch).  
**Linux / Ubuntu** — needs a desktop session; PortAudio / Tk deps are usually already satisfied when the package was built for your glibc.

After install, open the sidebar → **AUDIO OUTPUT** (pick a device) and **AGIU** (optional update check).
