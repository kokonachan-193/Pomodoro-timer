# Aqua Focus v1.1.0

> デスクトップ向けポモドーロ — ダウンロードしてすぐ使えます（ビルド不要）。

## 配布ファイル

| ファイル | 対象 | メモ |
| :--- | :--- | :--- |
| `AquaFocusSetup-1.1.0.exe` | Windows 10 / 11 | インストーラ · おすすめ |
| `AquaFocus-Windows-Portable-1.1.0.zip` | Windows 10 / 11 | 解凍 → `AquaFocus.exe` |
| `AquaFocus-macOS-1.1.0.zip` | macOS | 解凍 → `AquaFocus.app` |
| `AquaFocus-Linux-Portable-1.1.0.tar.gz` | Linux | `tar xzf … && ./AquaFocus/AquaFocus` |
| `AquaFocus-Ubuntu-Portable-1.1.0.tar.gz` | Ubuntu | Linux と同一ビルド |

どのパッケージにも **ffmpeg 同梱**です。

---

## このバージョンのポイント

- **AGIU** — GitHub Releases からアプリ内で更新（Windows / macOS / Linux）
- **音声出力** — 再生デバイスを自分で選択（自動選択なし）
- Focus 音楽（YouTube / Spotify / 直リンク）は作業中のみ
- 誘惑排除 · 日本語 / English · 学習科学プリセット

---

## インストールのヒント

**Windows** — Setup を実行、または Portable を好きな場所に解凍。  
**macOS** — Gatekeeper で止まったら、初回は右クリック → 開く。  
**Linux / Ubuntu** — デスクトップ環境向け。展開後に `./AquaFocus/AquaFocus`。

起動後、サイドバーの **AUDIO OUTPUT** で出力先を選び、必要なら **AGIU** で更新確認。
