# Aqua Focus v2.1.0 — Attention-first redesign

**One task. One session. Less interface.**

v2.1.0 is a full UI reset for Aqua Focus. The v2.0 feature set remains available, but the default experience no longer exposes everything at once.

## What changed

### Home was rebuilt
- one clear intention field
- three session choices: 25 / 50 / 90
- one primary **Start focus** action
- Sound is optional and collapsed
- Tasks / Stats / Settings are secondary actions
- Countdown / Stopwatch / Alarm / Extensions moved under **More**

### Focus was rebuilt
- large timer
- thin circular progress indicator
- one current intention
- quiet deep-sea light and sparse particles
- Pause / Stop controls appear only at the start, on interaction, while paused, or during breaks
- no album-art disc, equalizer, cycle diagram, persistent tips, or last-10-seconds urgency pulse

### New visual system
- **Abyss Glass** default theme
- fewer colors
- stronger spacing and hierarchy
- large empty areas are intentional
- Reduce Motion remains supported

### Psychology / usability direction
The redesign follows progressive disclosure: common actions remain visible, while advanced and occasional controls are deferred. Aqua Focus also treats natural / underwater visuals as a low-stimulation atmosphere rather than claiming they guarantee better concentration.

Design notes:
- `docs/attention-first-ui.md`
- `docs/aqua-focus-v2-concept.md`

### Android
Android now follows the same hierarchy:
- one task
- duration
- timer
- Start
- optional Sound drawer
