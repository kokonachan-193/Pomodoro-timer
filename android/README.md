# Aqua Focus Android

Android companion for Aqua Focus v2.1.6.

## Focus visuals

The Android Focus screen now uses the same Aqua visual language as desktop:

- translucent rising water body (not a rising frame)
- animated dual wave surface
- underwater caustics
- bubbles
- bioluminescent particles
- circular timer guide
- per-effect toggles
- Japanese / English UI

## Included

- Focus / break timer
- 25/5, 50/10 and 90/20 presets
- persistent timer / visual settings
- Android notifications
- touch-first scrolling UI
- YouTube / direct HTTP audio through Android MediaPlayer
- volume control

## Build

```bash
cd android
buildozer android debug
```

GitHub Actions produces:

`AquaFocus-Android-2.1.6.apk`
